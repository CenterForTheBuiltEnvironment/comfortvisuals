# comfortvisuals

This code contains r code functions to visualize thermal comfort results from EnegyPlus simulation results. To use this place the simulation results in 'sims' folder. Run the comfort\_visualizations\_for\_EnergyPlus.Rmd. The plots are saved in 'plots' folder.



\*\*Suggested citation\*\*



Nambiar, C., Kramer, T., and Schiavon, S. (2026). \*Visualizing EnergyPlus Thermal Comfort Outputs: A Question-Driven Guide\* (v1.0). Center for the Built Environment, University of California, Berkeley.https://doi.org/10.5281/zenodo.24206624
